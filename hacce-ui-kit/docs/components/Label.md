# Label

Etiqueta accesible para un control de formulario.

## Cuándo usarlo

- Una por campo, en estilo frase y sin dos puntos: “Correo electrónico”.
- Únela al control con `htmlFor` + `id`.

## Qué tienes que pasarle

`htmlFor` y los atributos de `<label>`.

## Ejemplo

```tsx
<Label htmlFor="cond">Acepto las condiciones</Label>
```
