# Textarea

Campo de texto de varias líneas que crece con el contenido.

## Cuándo usarlo

- Motivos, comentarios, descripciones.
- Indica el límite de caracteres con texto `text-muted-foreground` debajo.

## Qué tienes que pasarle

Todos los atributos de `<textarea>`.

## Ejemplo

```tsx
<Label htmlFor="motivo">Motivo</Label>
<Textarea id="motivo" placeholder="Cuéntanos brevemente el motivo" />
```
