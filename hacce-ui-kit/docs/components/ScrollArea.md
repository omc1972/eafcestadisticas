# ScrollArea

Zona con desplazamiento propio y barra discreta.

## Cuándo usarlo

- Listas dentro de paneles de alto fijo, menús largos. Da siempre una altura (`h-48`).

## Qué tienes que pasarle

`ScrollArea` con `className` de tamaño; `ScrollBar orientation="horizontal"` para desplazamiento lateral.

## Ejemplo

```tsx
<ScrollArea className="h-48 rounded-md border">…</ScrollArea>
```
