# Skeleton

Marcador de carga con la forma del contenido que viene.

## Cuándo usarlo

- Mientras cargan tarjetas, listas o tablas (más de 300 ms). Reproduce la forma real: líneas de texto, avatar redondo.

## Qué tienes que pasarle

`className` con el tamaño y la forma (`h-4 w-48`, `size-12 rounded-full`).

## Ejemplo

```tsx
<Skeleton className="h-4 w-64" />
```
