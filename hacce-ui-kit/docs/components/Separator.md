# Separator

Línea que separa bloques o elementos en línea.

## Cuándo usarlo

- Entre secciones de una tarjeta o menú, y entre enlaces en línea (`orientation="vertical"`).

## Qué tienes que pasarle

`orientation` (`horizontal` | `vertical`) y `decorative`.

## Ejemplo

```tsx
<Separator className="my-4" />
```
