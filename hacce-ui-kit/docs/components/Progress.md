# Progress

Barra de progreso de una tarea o un objetivo.

## Cuándo usarlo

- Avance medible (formación, subida de archivos). Muestra también el porcentaje en texto.

## Qué tienes que pasarle

`value` (0–100) y `aria-label`.

## Ejemplo

```tsx
<Progress value={60} aria-label="Formación obligatoria" />
```
